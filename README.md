# ARTISTRY Derma-Architect

**Бизнес план и работни процедури за дерма-естетичен кабинет**

A comprehensive business planning and operations management system for a dermatology aesthetic clinic built with Next.js and deployed on Vercel.

## Features

- 📋 **Interactive Document Viewer** — Browse all business documents in one place
- 📱 **Responsive Design** — Works seamlessly on desktop, tablet, and mobile
- 🌙 **Dark Theme** — Professional, eye-friendly interface
- 🇧🇬 **Bulgarian Language** — Complete documentation in Bulgarian

## Documents Included

1. **Стартов чеклист** — Pre-launch checklist with blocking requirements
2. **Риск-регистър** — Risk register with 10 identified risks and mitigation strategies
3. **Кабинетни протоколи** — Cabinet protocols with cost and margin analysis
4. **Финансов модел** — Financial model with pricing and break-even analysis
5. **Пазарно проучване** — Market research with 47 price points from 27 Sofia locations
6. **Бенчмарк на уредите** — Equipment benchmark and competitive analysis
7. **Хигиенен протокол** — Hygiene protocol (draft)
8. **Информирано съгласие** — Informed consent form (draft)
9. **Оптимизиран промпт** — Optimized initial requirements

## Tech Stack

- **Next.js 14** — React framework with App Router
- **TypeScript** — Type-safe development
- **Vercel** — Deployment and hosting

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Visit `http://localhost:3000` to view the application.

## Deployment

This project is deployed on Vercel. Visit: https://salon.teamenjoyvd.vercel.app
